# Adaptation for Buatin

Derived from Miqdad Badjuber's Anti Slop core at 671ab15c2ff6913cdd80717f602a89f0a9429a4b.
MIT. Original attribution and license retained.

The core is adapted into instruction-only specification guidance. The upstream
first-run wizard, global preferences, optional skill installers and runtime
scripts are excluded. Buatin preserves the user's locked visual preferences
and never treats generated checks as proof that the target app was tested.

Apply Anti-slop as a purpose test on the existing brand and locked user preferences. Explain major choices in layout, typography, color and motion. Build composition around real product content; avoid generic template sections and decoration without a purpose. Never invent testimonials, statistics, team identities, security claims or working features. Use specific action labels and real navigation targets. Specify responsive layouts, keyboard access, visible focus, contrast, reduced motion and truthful loading, empty and error states. Review design direction, purpose, identity and functional completeness before delivery; record actual checks and unresolved failures. Do not force new colors, fonts, themes or features, run the upstream installation wizard or execute third-party scripts.
