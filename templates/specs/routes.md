# Routes

## Inventaris halaman

Buat tabel path, tujuan, peran, akses publik/privat, data, CTA dan dokumen kebutuhan. URL dinamis mempunyai aturan identifier, slug dan penanganan resource tidak ditemukan.

## Rendering dan navigasi

Pilih SSG/SSR/streaming/CSR per halaman berdasarkan kebutuhan. Konten publik utama tersedia dalam HTML; tetapkan canonical, metadata, navigasi, breadcrumb dan deep link bila relevan.

## State dan otorisasi

Definisikan loading lokal, kosong, error, offline, 404 serta sesi kedaluwarsa. Pemeriksaan role/ownership wajib di server. Redirect tidak menggantikan kontrol API.

## Verifikasi rute

Uji akses langsung, refresh, back/forward, pagination, akun lain, query invalid, keyboard dan viewport kecil. Tautkan hanya dokumen yang dipilih dalam paket.
