# Search

## Tujuan dan relevansi

Definisikan data yang dapat dicari, peran, bahasa, normalisasi, typo/stemming bila dibutuhkan dan urutan hasil yang bermakna.

## Kontrak query

Tetapkan panjang minimum/maksimum, debounce, filter/sort, pagination dan representasi query dalam URL. Parameterisasi query; jangan membuka indeks data privat.

## State dan performa

Tentukan kosong sebelum mencari, loading nyata, tidak ditemukan, error, offline/cache dan respons usang. Batalkan request yang tidak relevan; jangan menimpa hasil query baru dengan respons lama.

## Verifikasi

Uji input ekstrem, injection, ownership, kombinasi filter, keyboard, reset URL dan latensi pada volume representatif. Pilih search engine khusus hanya bila kemampuan database tidak cukup.
