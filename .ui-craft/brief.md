# Bantuin

Indonesian SaaS document workshop for individuals turning website briefs into actionable specifications. Public verified accounts; Free once lifetime, Pro Starter/Plus/Max with weekly allowances.
Manual monthly QRIS renewal through Duitku. No Docker.
Primary action: prepare a brief, approve its document plan, inspect the generated package.
Product language, compact operational layout, variance 4. Signature: a document folio motif in the empty state and result explorer.
Light mineral surfaces, forest accent, purposeful serif titles paired with a humanist sans body.
No fabricated usage statistics or mock results presented as real AI output. Every mock run is visibly labeled.
Mobile first, keyboard usable, readable long-form Markdown, clear partial/error/offline states.
